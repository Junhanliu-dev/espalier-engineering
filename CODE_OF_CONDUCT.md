# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

- Be respectful and constructive in all interactions.
- Assume good intent. Ask clarifying questions before reacting.
- Critique ideas, not people.
- Use welcoming and inclusive language.

## Scope

Applies to all project spaces: GitHub issues, PRs, discussions, and any communication channels associated with this repository.

## Enforcement

Report concerns to the project maintainer (see `README.md` author field). Reports will be reviewed promptly and confidentially. Maintainers may take any action deemed appropriate, up to and including blocking participation.
